   130→## 9. Hubtel payment integration — required
   131→
   132→Hubtel is the initial provider for Ghana collections and supported payouts. Use hosted checkout or an officially supported flow so card credentials do not enter our application.
   133→
   134→Read current official Hubtel documentation before coding. Implement the real adapter with separately configured credentials/account IDs per API. Never expose secrets in web/mobile bundles, public variables, URLs or logs.
   135→
   136→Important contract rules:
   137→- Checkout creation and a browser return URL do not prove payment.
   138→- Create unique references within the documented limits for the selected API. Persist references and provider IDs before asynchronous processing.
   139→- Store incoming callbacks durably, acknowledge promptly, and process business effects idempotently.
   140→- The presently published v1 callback contract does not define a production verification signature. Do not invent HMAC verification or assume a sandbox signature exists in production. Use documented ingress controls and authenticated server-to-server transaction verification.
   141→- Compare the original order, reference, amount and applicable currency context before granting tickets, subscriptions, boosts or viewing rights. Handle omitted provider fields according to the documented endpoint contract; do not silently accept a conflicting currency.
   142→- Reconcile unresolved transactions when callbacks are missing, including the documented status-check requirement after five minutes. Retry boundedly with backoff, maintain an operations queue and avoid hammering the provider.
   143→- Treat ambiguous/Unpaid results as unresolved until evidence supports a final state. A timeout alone must not create a new charge or erase a confirmed payment.
   144→- Handle duplicates, stale callbacks, multiple attempts for one order, unknown references, provider outages and late success.
   145→
   146→Implement payment success, failure, pending, unknown/review and reversal paths. Preserve the raw provider event safely with sensitive fields redacted from routine logs.
   147→
   148→Use integer minor units or exact database decimals, never floating-point arithmetic for money. Ghana UI amounts must display the cedi symbol, two decimal places and thousands separators. The provider's required ISO currency code remains valid in API/internal fields.
